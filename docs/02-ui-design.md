# 02. UI 디자인 지침

## 참고 이미지
`assets/ui-reference.jpg`는 사용자가 제공한 스타일 레퍼런스.
- 분위기: 2000년대 Y2K 레트로 게임 시작 화면, 픽셀 아트, 반짝이 스티커, 스크랩북 감성.
- 색: 선명한 코발트/하늘색 배경 + 핫핑크 버튼 + 라벤더 + 은색/화이트.
- 요소: 굵은 픽셀풍 제목, 네모난 3D 게임 버튼, 글리터·별·하트·나비 느낌의 장식.
- **이미지 속 원본 상표/로고/텍스트/저작권 문구는 그대로 사용하지 않는다.** 자체 브랜드 문구와 CSS 장식으로 재해석한다.
- 사용자 제공 이미지는 디자인 참고용이며 배포 사이트의 배경에 통째로 삽입하지 않는다.

## 브랜드
- 화면 메인 타이틀: `Who’s your bias? I’m Your Bias!`
- 한글 서브카피: `사주오행으로 보는 내 최애와 나의 궁합도`
- 메인 버튼: `START`, 분석 버튼: `궁합 분석하기`, 결과 버튼: `다시 분석하기`
- 영어는 포인트만, 설명은 한국어.
- 하트·별 이모지와 CSS 효과 활용, 과도한 애니메이션 지양.

## 화면 구역
1. **히어로/시작**: 파란 레트로 게임 패널, 픽셀풍 타이틀, 핑크 START 버튼.
2. **입력**: '나의 생일' 날짜 선택, '최애 이름' 텍스트, '최애 생일' 날짜 선택. 입력 폼은 읽기 쉬운 밝은 카드.
3. **로딩**: 별 반짝임 또는 진행 아이콘 + '우리의 케미를 분석 중...'.
4. **결과**: '나'와 '최애' 오행 카드 나란히, 관계 화살표, 점수 크게, 한 줄 총평, AI 해설, 연애/결혼 카드 2개, 다시 분석하기 버튼.
5. **방명록**: 페이지 하단. 닉네임/내용 입력 + 등록 버튼 + ❤️ 아바타 댓글 목록.
6. **토스트**: 상단 고정, ⚠️ 경고/✓ 성공, 3초 후 사라짐.

## 스타일 세부
- 픽셀/게임풍은 제목과 버튼 위주. 본문은 가독성 높은 시스템 글꼴.
- 패널 테두리: 두꺼운 짙은색 선 + 밝은 하이라이트 + 그림자.
- 버튼: 누를 때 살짝 내려가는 CSS 효과.
- 오행 카드: 목 초록, 화 빨강, 토 황토, 금 은색, 수 파랑. 색뿐 아니라 한글/한자 텍스트 병기.
- 320px 모바일부터 데스크톱까지 가로 스크롤 없이 표시.
- 모바일에서는 오행 카드가 너무 좁아지면 세로 배치.
- `prefers-reduced-motion` 지원, 키보드 포커스 스타일, 적절한 레이블 및 명도 대비.
- 장식 요소는 스크린리더에 읽히지 않도록 처리.

## 구현 제약
- UI는 HTML/CSS/JS만 사용.
- 외부 유료 이미지·폰트·아이콘 의존 금지. 폰트는 라이선스 확인 후 적용하거나 시스템 대체 폰트 사용.
- 원본 이미지의 저작권 표시, JYP 문구, 'Level Up', 'DREAM' 등 고유 요소를 복제하지 않는다.
